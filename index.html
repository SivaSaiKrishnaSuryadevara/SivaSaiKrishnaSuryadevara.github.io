About

Siva Sai Krishna Suryadevara is a Senior DevOps Engineer and Cloud Platform Architect with extensive experience designing, engineering, and operating secure, highly available AWS cloud platforms and GitOps automation frameworks for multi-tenant SaaS environments in regulated healthcare and enterprise domains.

He specializes in Infrastructure as Code (IaC) using AWS CDK (TypeScript) and CloudFormation, Amazon EKS cluster architecture, zero-trust cloud security (IAM, AWS WAF, KMS), and resilient CI/CD pipelines via GitHub Actions and ArgoCD under strict compliance standards (GxP, HIPAA, GDPR, NIST). His independent research focuses on autonomous DevSecOps agents, AI-driven failure remediation, and edge-cloud orchestration.
